# Pipeline tenant UI audit — 2026-10-12

The tenant now uses compact shared page headers, wrapping shared toolbars, consistent small controls, and icon actions with accessible names and hover/focus tooltips. Covered Definitions, Runs, Approvals, Artifacts, Runbooks, Queues, Agents, Bots, Commands, Configuration, and Activity, plus run detail, definition/approval drawers, and report-deck actions.

Shared fixes ship in ui-components 2.440.1: compact and collapsed PageHeader retain back navigation; DataTable pagination uses shared icon buttons and constrains wide content within its parent. The portal consumes the built vendored package. Run detail keeps the same header geometry when switching tabs. Queue implementation details are collapsed. Configuration has an explicit approver-role field label. Report-deck request failures now show a retryable error instead of an empty result.

Validation:

- 29 shared component tests passed; library build passed.
- Portal TypeScript check and 32 pipeline/deck unit tests passed.
- 7 Chromium tests passed, including 44 page/theme/width combinations (11 pages, light/dark, 1280/480 pixels), keyboard pagination, search, drawer actions, compact back navigation, stable tab geometry, permission-sensitive actions, and queue partial-failure presentation.
- Browser checks assert no page-level horizontal overflow or uncaught errors. Wide tables retain their own horizontal scrolling. Representative light/dark desktop and narrow screenshots were inspected.
- A CDP Performance session collects metrics during the interaction check; this is diagnostic instrumentation, not a production latency benchmark.

The browser suite mounts real page components with isolated HTTP fixtures and an offline gateway. It does not exercise production data, paid automation, or live gateway throughput. All API writes are intercepted and asserted absent. The existing local API/Vite/media session was preserved; these changes require a later frontend activation to appear there.

Reproduce against an isolated Vite server with the portal dependencies installed:

```sh
PARITY_BASE_URL=http://127.0.0.1:5283 npx playwright test e2e/pipeline-ui.spec.ts e2e/pipeline-queues.spec.ts
```
