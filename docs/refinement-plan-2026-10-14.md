# Refinement plan — 2026-10-14

Goal: more of the app verified by machines, fewer defects found by the user's
eye. The UI DOM audit judges geometry; it can only judge what it is shown. Two
foundations widen what it is shown — a mock that can render any data state for
one browser context without touching shared state, and journeys that are
executable maps rather than hand-walked logs — and the audit then runs at every
step of every journey. Everything here is local; nothing needs AWS.

## Lanes

| lane | what | depends on | done when |
|---|---|---|---|
| M — mock isolation | Request-scoped scenarios (a header/cookie the dev-mock BFF honours per request, never global) and ephemeral identity clones (a test user minted from a seed persona, same grants, own session epoch) so audits, journeys and e2e run in parallel without revoking each other or damaging shared state | — | contracts prove a scoped scenario never leaks to another session; two browser runs as clones of one persona coexist; `validate-mock-floor.sh` green |
| J — executable journey maps | Journeys as data (role × goal × steps × expected states), walked headlessly by one runner that applies the DOM audit at every step, writes the journey log and seals it; a coverage map of route × state × role | M (clones, scoped scenarios) for parallel runs; can start on the format and runner | a family's hand-written logs are regenerated by the runner and the family's validator stays green; coverage map published |
| D — deep audit | Deeper criteria in the skill (outliers, whitespace, alignment, interaction depth, tab stability, data states, widths, content honesty, a11y, theme parity, read-only coherence, screenshot review) and a ranked findings list | running | findings report; then one fix lane per defect class |
| T — type honesty | Remove `ignoreCodes` TS2307/TS2304/TS2345 from `middleware/jest.config.cjs` and fix what surfaces | — | jest runs with full diagnostics, 0 failed |
| L — library health | The nine unit tests that fail on ui-components main | — | library suite 0 failed |
| A — access tenant | Native PostgreSQL contracts for requests/steps, the admin wizard person picker, escalation timers and delegation | — | `validate-access-tenant.sh` green with the new checks |
| B — burn-downs | `type-scale-burndown.tsv` (594) and `layout-drift-burndown.tsv` (120) by tenant | M (parallel browser runs) | lists at zero or each remaining row owned |

## Order

T, L, A, M start now (no shared browser identities). D is running. J starts on
format and runner now and goes parallel once M lands. B and the deep-audit fix
lanes follow M so their browser runs no longer queue behind one identity.

## Rules for every lane

Headless Playwright only. Never two browser runs as the same identity (until M
lands, check `pgrep -f audit.mjs`). Stop only PIDs you started. No writes to
business records outside a lane's own scoped scenario or clone. Library first:
a missing primitive ships to ui-components before a page uses it. Each lane
commits only the paths it changed, with the Opus trailer.
