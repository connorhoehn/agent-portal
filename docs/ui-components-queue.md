# Composites queued for the component library

Gaps found while building pages. Each row is a workaround in this repository and what the library should absorb. No row here exempts a file from the component-discipline gate (`scripts/lib/discipline.sh` only honours rows that say a file is composed locally).

| Found in | Gap | Worked round with |
|---|---|---|

Wanted: `focusTitleOf?: slideId` (or `onSlideAdded` returning `{ selectTitle: true }`) on `PresentationEditor`. |
| `portal/src/components/decks/DeckEditorPage.tsx` (deck polish) | `PresentationEditor` puts the stage and the slide form in one scrolling region (`<prefix>-main`) and sizes the stage to that region's full height, so typing in the form scrolls the slide being edited out of view (the walk measured about a third of it left). | Nothing on the page fixes it: the whole editor also scrolls by the height of the findings line (about 20px), and moving that line out of the scroller cost the stage about 80px and pushed Theme behind ⋯, so it stays. Wanted: the stage pinned above a form region that scrolls on its own (or a side-by-side form at wide widths). |
| `portal/src/components/decks/DeckEditorPage.tsx` (deck walk fixes) | `PresentationEditor`'s filmstrip has no per-slide slot for the preview's findings (overflow, unfinished, example source), so a slide's own problems cannot be marked on its thumbnail. | The compact findings line above the stage names the slides ("Overflow (slide 5)").
